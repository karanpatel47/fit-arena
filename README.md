# fit-arena
AI-Powered Fitness Application – “Fit Arena” (GitHub)
• Built a scalable, cloud-native fitness platform using microservices architecture to provide personalized health
and workout analytics.
• Integrated various services including User, Workout, Activity, AI Recommendation, and frontend via Eureka
Server and Spring Cloud Gateway.
• Implemented event-driven processing using Apache Kafka to stream real-time activity and workout data.
• Used Keycloak for centralized authentication and authorization across microservices (OAuth2, RBAC).
• Utilized Google Gemini API to generate AI-powered workout and diet recommendations based on user health
patterns.
• Tech Stack: Spring Boot, React, Eureka Server, Spring Cloud Gateway, Keycloak, Apache Kafka, PostgreSQL /
MySQL, Google Gemini API, Spring Cloud Config Server, Docker
